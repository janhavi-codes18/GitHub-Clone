# GitHub Clone

A MERN-based GitHub replica with custom version control implemented from scratch.

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript

## Project Structure
- frontend-main – React frontend
- backend-main – Node.js and Express backend
